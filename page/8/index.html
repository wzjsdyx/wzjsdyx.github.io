Xcelium仿真器命令语言是基于TCL，能够对模拟器中的对象执行各种操作。

The Tcl Command-Line Interface

Tcl Command Syntax

Tcl Command Rules

  • 命令的名称必须小写

  • 可以使用略缩表达

  • 一行可以有多个tcl命令，使用;分割

Command Description Conventions

  • 格式符号 的作用是规范 Tcl 命令的书写和使用，方便用户理解命令中的必填和可选部分。
  • 核心规则：
    1. 必须输入的部分: 使用字面量。
    2. 可选部分: 用方括号 [ ] 标注。
    3. 选择其中一个: 用竖线 | 和大括号 { } 表示。
    4. 重复参数: 用省略号 ... 表示，方括号则标明是否可以完全省略。

通过这些符号的配合，Tcl 命令的表达既清晰又灵活，适应多种使用场景。

libc.so.6丢失

libc.so.6是一个动态链接库文件，是GNU C Library的一个共享函数库

可以这么说，Ubuntu下有个问题，好多文件都在/lib/x86_64-linux-gnu/下，弄得很麻烦，需要做软连接才可以使用。更巧的是，这个libc.so.6需要手动链接一下。

知道咋回事了，就开始做吧：

1、查找libc.so.6文件的具体路径

通常情况下Ubuntu下是这样的：

32bit: /lib/i386-linux-gnu/libc.so.6

64bit: /lib/x86_64-linux-gnu/libc.so.6

此外使用命令查看：

#dpkg -L libc6

2、软链接

ln -s /lib/x86_64-linux-gnu/libc.so.6 /lib/libc.so.6

常见颜色设置

ANSI 颜色代码分为两部分：前景色（文字颜色） 和 背景色。

颜色 代码（前景色） 代码（背景色） 示例
黑色 30 40 \033[1;30m 黑色文字
红色 31 41 \033[1;31m 红色文字
绿色 32 42 \033[1;32m 绿色文字
黄色 33 43 \033[1;33m 黄色文字
蓝色 34 44 \033[1;34m 蓝色文字
品红色 35 45 \033[1;35m 品红文字
青色 36 46 \033[1;36m 青色文字
白色 37 47 \033[1;37m 白色文字

设置方法示例

代码说明

  1. \033 或 \x1B：
    • ANSI 转义序列的起始符，告诉终端接下来是控制命令。
  2. [1;36m：
    • 1：设置文本为高亮（粗体）。
    • 36：颜色代码，表示青色（cyan）。
  3. *******************************************************：
    • 打印的实际文本。
  4. \033[0m：
    • 终止颜色控制，将后续文本恢复到默认颜色

发表于 2024-12-09 更新于 2025-03-14 分类于 ARM ， Cortex-M4 Valine：

Cortex-M4 是基于 ARM 架构的处理器，支持字节（Byte）、半字（Half-word）和全字（Word）类型的数据访问。具体操作可以通过 C 语言的指针类型 来实现。

访问类型定义

访问类型 数据大小 C 语言类型 访问说明
Byte 8 位 uint8_t 或 char 访问一个字节
Half-word 16 位 uint16_t 或 short 访问两个字节
Word 32 位 uint32_t 或 int 访问四个字节

实现方式

通过指针类型来实现不同的访问大小。例如，假设一个外设寄存器地址为 0x40000000。
