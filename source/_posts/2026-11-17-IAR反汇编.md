# 命令参数

| 使用方式                                 | 输出内容                                                     |
| ---------------------------------------- | ------------------------------------------------------------ |
| 不指定 `--code`、`--all`、`--section` 等 | 默认输出 ELF 基本信息、段和节的信息，不包含各节的具体内容    |
| `--code`                                 | 输出包含可执行代码的节                                       |
| `--all`                                  | 输出所有节的内容，包括代码、数据等                           |
| `--section 节名`                         | 输出指定节的内容                                             |
| `--source`                               | 会把原始源码穿插到反汇编结果中，<font color=blue>这个会导致`地址:数据`直接被源代码替换</font> |
